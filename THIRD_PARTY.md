The port adapts these upstream areas:

| Upstream source | Adaptation in this repository |
|---|---|
| `src/raw/build.rs`, `src/raw/registry.rs` | Sorted incremental construction, output factoring and equivalent-node reuse |
| `src/raw/node.rs`, `src/bytes.rs`, `src/raw/common_inputs.rs` | Versioned compact node encoding, packed integers and common-input labels in `codec/` |
| `src/raw/crc32.rs`, `build.rs` | CRC32C polynomial and masked checksum semantics |
| `src/raw/mod.rs`, `src/map.rs`, `src/set.rs` | Immutable graph, set/map and lookup semantics |
| `src/raw/ops.rs` | Ordered multiway set-operation semantics |
| `src/automaton/mod.rs`, `src/automaton/levenshtein.rs` | Automaton composition and bounded edit-distance semantics |

This is a source-level adaptation to MoonBit, not a wrapper linking an upstream
binary. Public APIs, iterative graph validation, optional rank/select indexing,
reversible cursors, explicit DFA construction and finite scalar-class UTF-8
lowering are implemented for this project. The port does not claim to include
the upstream CLI, mmap adapter, regex integration or parallel construction.

## Reference oracle and fixtures

`oracle/Cargo.toml` pins the unmodified crates.io dependency `fst = "=0.4.7"`.
`oracle/Cargo.lock` pins its development-tool dependencies. Those dependencies
retain their own package licenses and are not linked into the MoonBit library.
The oracle source and Python acceptance scripts are development tooling.

Committed `.fst` fixtures are generated by that pinned upstream builder from
the synthetic inputs described in `fixtures/manifest.json`. Expected records
use hexadecimal byte keys and decimal-string u64 values. Generated MoonBit
embeddings are test data; they are not hand-written implementation code and are
excluded from production LOC.

## MoonBit standard library

The runtime imports MoonBit's standard-library UTF-8 and debug facilities and
uses its built-in collections and numeric types. These are toolchain
dependencies, not vendored copies. See the installed toolchain and
[`moonbitlang/core`](https://github.com/moonbitlang/core) for their applicable
license notices. The project's own `LICENSE` does not replace dependency
licenses.

## New contributions

The eight-byte zero-lane test in `packed.mbt` uses the public-domain
`haszero`/`hasvalue` arithmetic pattern documented in Sean Eron Anderson's
[Bit Twiddling Hacks](https://graphics.stanford.edu/~seander/bithacks.html#ZeroInWord).
The MoonBit traversal, tail handling, validation preconditions and differential
tests are project implementations.
